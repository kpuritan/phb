# Project Guidelines & Rules

## Git & Deployment Rule
- **Remote Repository**: `https://github.com/kpuritan/phb.git` (`origin/main`)
- Whenever commands, file modifications, or task implementations are performed in this project, changes should be committed with meaningful commit messages and pushed to `origin/main` on GitHub (`https://github.com/kpuritan/phb.git`).
- Ensure the working tree is clean and synchronized with the remote repository after completing tasks.
